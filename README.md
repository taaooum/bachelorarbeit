# KI-Unterstützung im Angebotsprozess

Bachelorarbeit (B.Sc. Wirtschaftsinformatik, Universität Siegen):
Eine Design-Case-Studie zur Entwicklung und Evaluation eines Konzeptes zur Projektstrukturplanungsunterstützung in einem KMU

Das Repository enthält die Arbeit in der abgegebenen Fassung und den
Prototyp, mit dem die Evaluation durchgeführt wurde.
